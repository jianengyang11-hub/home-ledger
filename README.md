# บ้านเรา · Home Ledger

บัญชีรายรับรายจ่ายของบ้าน — เข้าสู่ระบบด้วย PIN, ภาพรวมรายเดือน, สรุปรายปี,
รายการทั้งหมด, บันทึกข้อมูล และมุมมองมือถือ รองรับภาษาไทย / ลาว
ข้อมูลเก็บบน **Supabase** สองคนเห็นข้อมูลชุดเดียวกัน

## สิทธิ์การใช้งาน

| บัญชี | PIN | เพิ่มรายการ | แก้ไข / ลบ | หน้าตั้งค่า |
| --- | --- | --- | --- | --- |
| **ปิ่น** (บัญชีหลัก) | 111111 | ได้ทุกบัญชี | **ได้** | เห็น |
| ต้น | 222222 | ในชื่อ "ต้น" เท่านั้น | ไม่ได้ | ไม่เห็น |
| บ้านเรา | 123456 | ในชื่อ "บ้านเรา" เท่านั้น | ไม่ได้ | ไม่เห็น |

เปลี่ยนบัญชีหลักได้ที่ `ADMIN_ID` ในไฟล์ `config.js` (`pin` / `ton` / `home`)

> **ข้อจำกัดด้านความปลอดภัย**  PIN ทั้งหมดอยู่ในโค้ดหน้าเว็บ ใครกด View Source ก็เห็น
> และ anon key ของ Supabase ก็เปิดเผยอยู่ในหน้าเว็บเช่นกัน กฎ "แก้/ลบได้เฉพาะบัญชีหลัก"
> จึงบังคับที่ฝั่งหน้าเว็บเท่านั้น — กันการกดพลาดในบ้านได้ แต่กันคนที่ตั้งใจเจาะไม่ได้
> ถ้าต้องการกันจริง ต้องเปลี่ยนไปใช้ Supabase Auth (ล็อกอินด้วยอีเมล) แล้วเขียน RLS ผูกกับ user id

## ตั้งค่าครั้งแรก

1. สมัคร https://supabase.com → สร้าง project ใหม่ (ฟรี)
2. **SQL Editor** → วางเนื้อหาไฟล์ `schema.sql` ทั้งไฟล์ → Run
3. **Project Settings → Data API** → คัดลอก "Project URL"
4. **Project Settings → API Keys** → คัดลอก "anon / public"
5. เปิด `config.js` แล้ววาง 2 ค่านั้นแทน `PASTE_...`
6. อัปโหลด `config.js` ที่แก้แล้วขึ้น GitHub

## เปิดดูแบบ local

เป็นเว็บ static ล้วน ต้องเสิร์ฟผ่าน HTTP (เปิดด้วย `file://` จะไม่ทำงาน):

```powershell
cd "C:\JIA\สรุปลายรับลายจ่าย"
python -m http.server 8765
# เปิด http://localhost:8765/
```

## โครงไฟล์

| ไฟล์ | หน้าที่ |
| --- | --- |
| `index.html` | หน้าแรก — redirect ไป `Home Ledger.dc.html` |
| `Home Ledger.dc.html` | ตัวเว็บทั้งหมด (Claude Design canvas) |
| `config.js` | URL + anon key ของ Supabase และบัญชีหลัก |
| `schema.sql` | SQL สร้างตาราง `txns` — รันครั้งเดียวตอนตั้งค่า |
| `support.js` | runtime ที่ render `<x-dc>` โหลด React 18 UMD จาก unpkg |
| `_ds/industry-.../` | design system: `styles.css` + `_ds_bundle.js` |
| `.nojekyll` | จำเป็นสำหรับ GitHub Pages — ไม่งั้นโฟลเดอร์ `_ds` จะถูก Jekyll ข้าม |

## เรื่องสกุลเงิน

แต่ละรายการเก็บสกุลเงินของตัวเอง (THB / USD / KIP) และแสดงผลด้วยสกุลนั้น
ส่วนตัวเลขที่ต้องรวมข้ามสกุล (กราฟรายวัน, สรุปรายปี, งบประมาณ, %) จะแปลงเป็นฐานบาทก่อน
โดยใช้อัตราคงที่ใน `CURRENCIES` — แก้อัตราได้ในไฟล์ `Home Ledger.dc.html`

## Deploy บน GitHub Pages

อัปโหลดไฟล์ทั้งหมด **รวม `.nojekyll` และโฟลเดอร์ `_ds`** แล้วตั้ง
Settings → Pages → Deploy from a branch → `main` → `/ (root)`
